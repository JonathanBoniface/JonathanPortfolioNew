# Mon Portfolio

Ce projet est un portfolio personnel moderne, basé sur un template épuré et transformé en **Single Page App**.

## ✨ Fonctionnalités

- Chargement dynamique des sections HTML via JavaScript (`fetch`)
- Design responsive et animations visuelles
- Prêt à déployer sur **GitHub Pages**

## 📁 Structure

```
/
├── index.html
├── script.js (intégré dans index.html)
├── assets/
│   └── css, img, etc.
└── sections/
    ├── hero.html
    ├── projects.html
    ├── skills.html
    ├── advices.html
    ├── hobbies.html
    └── contact.html
```

## 🚀 Déploiement sur GitHub Pages

1. Crée un nouveau dépôt sur GitHub
2. Pousse les fichiers du projet dans le dépôt
3. Va dans **Settings > Pages**
4. Choisis la branche `main` et le dossier `/root` (ou `/docs` si tu y places les fichiers)
5. Ton site sera accessible à `https://<ton-username>.github.io/<nom-du-repo>/`

## 📝 Contact

Formulaire de contact prêt à être branché avec un service comme **Formspree** ou **Netlify Forms**.
